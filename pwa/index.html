使用說明
此 PWA 僅作為工作人員快速進入報到系統的入口， 不直接讀寫 Google Sheets。

開啟 Apps Script 控制頁後， 請依序按：
①「測試 Apps Script 後端」
②「啟動連續掃碼器」
③ 掃碼頁的「啟用相機＋測試報到語音」
系統狀態： 等待啟動
活動當天操作順序
  1. 點手機主畫面的「CEO報到」。
  2. 確認畫面顯示「網路已連線」。
  3. 點「啟動 Apps Script 報到控制頁」。
  4. 在 Apps Script 控制頁按 「測試 Apps Script 後端」。
  5. 確認測試成功後， 按「啟動連續掃碼器」。
  6. 在 GitHub 掃碼頁按 「啟用相機＋測試報到語音」。
  7. 開始連續掃描來賓 QR Code。
